# GoDocs Homepage

## About The Project
This project is a single-page implementation of the GoDocs documentation website template. It was created as a front-end practice project to apply HTML, CSS, and Bootstrap concepts.

## Built With
- HTML5
- CSS3
- Bootstrap

## Features
- Navigation bar
- Hero section with a search bar
- Documentation-themed layout
- Responsive design

## What I Learned
- Building layouts with Bootstrap
- Structuring a webpage using HTML
- Customizing styles with CSS
- Practicing front-end development skills

## Project Scope
This project includes one page of the original multi-page template, developed as part of a practical learning assignment.
